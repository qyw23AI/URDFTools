# 训练适用性评估、对照实验与机械反馈协议

版本 1；2026-10-22。这里规定实现和验收要求，不代表已经获得实验结果。

## 1. 评估对象

评估输入是 `(RobotSnapshot, ActuatorProfile, ContactProfile, TaskSpec, ControllerSpec, TrainingRecipe, EngineSpec)`。输入缺项时给出资料缺失，限定结论范围。URDF 结构正确不保证质量参数真实；真实参数也不保证任何控制器都能训练成功。推荐输出多维诊断与 Pareto 对照，不生成缺乏任务依据的统一「URDF 好坏分」。

机器人类别包括 quadruped、humanoid/biped、manipulator、wheeled、other；第一版完整标定四足和人形。分类器依据运动树和接触语义给候选，用户确认 feet、knees、hips、trunk、hands 等角色；左右/前后镜像不是仅靠 joint name 猜测。未知类型运行通用规则而不套四足阈值。

## 2. 五层证据

| 层 | 方法 | 可支持的结论 |
|---|---|---|
| E0 描述和资源 | XML/图结构/单位/引用/关节定义/包路径检查 | 可定位的格式、资源、语义错误 |
| E1 物理一致性 | CAD/测量来源、惯性可实现性、独立 FK/动力学计算 | 参数不自洽或高风险，资料不足时不声称实际质量错误 |
| E2 无训练动态探测 | 编译、重力、关节阶跃、摆动、落地、站立、限位与碰撞扫掠 | 给定模拟器和控制配置下的局部行为 |
| E3 同协议 RL | 固定任务、重复种子、固定预算与独立测试地形 | 在该训练协议下的性能与学习效率及不确定度 |
| E4 归因/改进 | 参数敏感度、单变量消融、匹配训练预算、独立复验 | 假设或局部因果证据；不保证实体可靠性 |

每个 Finding 包含 rule/version、severity、对象 UUID、source span/part、观测值、单位、参考范围及出处、适用条件、证据 artifact、置信依据、建议、验证动作。分类是 `description_error|physical_inconsistency|design_risk|missing_data|simulation_issue|training_issue|hypothesis`，避免把所有低分都归咎机械。

## 3. E0 与 E1 的最低规则集合

- 名称唯一、单 root、连通、无非法环、parent/child 存在、轴非零且可归一化、关节类型与范围匹配、mimic 无环且目标存在；mimic offset/multiplier 的限位联动检查。
- 所有数字有限、质量/惯量单位正确，mesh scale 明确；不存在自动 mm→m 猜测后直接保存。无质量的 fixed frame 与有自由度刚体区别处理，避免误报传感器 frame。
- inertia 对称、在质心坐标下检查特征值及主惯量三角不等式；数值容差相对于质量和尺度设置。SPD 不是充分物理条件。用 [Drake 惯性定义](https://drake.mit.edu/doxygen_cxx/classdrake_1_1multibody_1_1_rotational_inertia.html) 作为来源，覆盖退化薄体等边界。
- 坐标变换：`I_B = R I_C R^T + m (||d||² E - d d^T)`；质量组合必须先求总质心，再在统一 frame 求惯量。用旋转长方体、偏置双球、非对角惯量、多零件合并作为解析夹具。
- CAD 值与 URDF 值按同一零件集合和坐标比较；记录密度/空腔/电机/线束是否建模。缺材料只能给假设区间。质心在真实质量分布凸包外可提示不一致，不能把中空模型质心位于网格实体外当成必然错误。
- 不用 visual mesh 的外观体积自动覆盖惯量。不完整/非流形三角网格计算体积时给出不可靠标记；凸包或 collision 简化只能用来碰撞估计。
- 接触几何：碰撞/视觉偏差、网格复杂度、穿插、碰撞代理、足底尺寸与接触面、离地间隙。初始接触和允许相邻 link 接触须配置；不能把任意交叠都当作碰撞错误。
- 关节限位、传动比、扭矩/速度、阻尼、摩擦、转子惯量、延迟与饱和：URDF effort/velocity 不构成完整电机模型。电机速度转矩曲线及连续/峰值限制从 sidecar 读取，缺失则禁用相应结论。
- FK、多姿态质量矩阵、重力项、雅可比与 Pinocchio/MuJoCo 交叉核验；frame/freejoint 表达差异须先对齐。[Modern Robotics](https://modernrobotics.northwestern.edu/nu-gm-book-resource/8-1-3-understanding-the-mass-matrix/) 支持将质量矩阵视为姿态相关的物理量。
- 尺度归一化后比较 limb length、质量比例、远端转动惯量、工作空间、关节活动裕量、foot clearance。静态支撑多边形的质心投影只用于准静态情境，不能据此否定动态步态；雅可比条件数须标注位置/姿态量纲与缩放。

所有启发式阈值在规则文件标为 heuristic，附适用尺寸/机器人类、版本和正反例；未知不自动判 pass。规则阈值可以从参照库估计分布，但参照模型数量少时只报告分布，不称为行业标准。

## 4. 模拟转换与 E2

MuJoCo 编译支持 URDF，但 URDF 默认项、惯量推断、固定 link 融合、路径和碰撞处理可能影响编译结果，详见 [MuJoCo modeling](https://mujoco.readthedocs.io/en/stable/modeling.html) 与 [compiler reference](https://mujoco.readthedocs.io/en/stable/XMLreference.html#compiler)。导入器必须显式记录这些配置，不开启 balanceinertia/boundmass 等补丁后隐藏源错误。

保存源 URDF → RobotDocument → MJCF 的 link/joint 映射、自由度数量、总质量、质心、逐 link 惯量和 FK 差异。碰撞 mesh 在模拟器中的凸包近似必须列入损失报告；碰撞分解采用 CoACD/简单体拟合并允许查看对照。闭环机构单列支持范围。

动态探测套件：

1. 固定基座单关节低幅值阶跃/正弦扫频：正负轴、饱和、延迟、稳态误差。
2. 不接触自由运动/简摆：能量趋势与解析周期在指定数值容差内；区别阻尼和数值耗散。
3. 放置/落地/站立：接触穿透、solver warning、非有限状态、抖动、稳定持续时间。
4. 工作空间/关节极限扫掠：自碰撞、可达性、奇异姿态附近灵敏度；有限采样不能声称全局无碰撞。
5. 低强度推扰与姿态恢复：控制器已明确、扰动大小和方向固定，并记录失败条件。

探测结果是特定控制配置下的证据，PD 参数错误先排查。视频附时间戳、相机、速度与关节/接触 overlay，指标可点选定位视频区间。

## 5. RL 对照实验设计

首批 reference families 为 A1/Go2 和 G1/H1。厂商 URDF、Menagerie MJCF 视为不同资产版本，需要转换核验后才可对比；不得假定同名型号在不同 repo 的质量和电机配置一致。

比较采用两条分开的实验轨道：

- 固定配方：相同算法、环境步数预算、任务、控制频率、奖励定义、网络/归一化规则、训练与测试种子策略、扰动分布。衡量该既定配方下的可训练性。
- 有界调参：每个机器人相同数量/计算预算的候选配置，验证集选择，再在未用测试种子/地形评估。防止把“只为 A1 调过参数”误认为 A1 的机械优势。

不能直接把不同动作维度的已训练策略互相套用；迁移试验另列。原始 reward 对跨任务/不同 reward 配置不可比；主比较使用物理任务指标，并保存完整奖励分量。

实验 manifest 必含：机器人与所有资产 hash、joint/foot 映射、质量/接触/执行器配置、engine/build/solver/time step、control decimation、观察/动作/PD/饱和、算法与超参、train/eval seeds、训练环境步数和墙钟、随机化分布、终止规则、地形 seed、代码 commit/依赖锁、硬件、checkpoint/normalizer/optimizer/RNG 状态、许可证及来源。

基准分层：

- `smoke`：1 seed、短训练，验证真训练/保存/恢复/视频管道；永远不进入标准性能库。
- `pilot`：至少 3 独立训练 seed、声明预算；可发现问题，统计结论限定。
- `reference`：默认至少 5 独立训练 seed，每 seed 至少 20 个独立测试 episode；实际不确定度过大则继续采样，不能认为“5 次即充分”。计算量允许时增加到 10+。全部保留，不能挑最佳种子视频/分数代表总体。

统计单位为独立训练 seed，测试 episode 嵌套在 seed 内；不要把同一个策略的 100 个 episode 当作 100 次独立训练。可用 rliable 进行分层 bootstrap、IQM 和改善概率，见 [rliable](https://github.com/google-research/rliable)。单种子不报告跨训练种子置信区间。

训练/验证/测试地形与种子预先分开。对标准和自有模型，报告两种尺度协议：相同真实场地要求（米、m/s）与无量纲任务（腿长、Froude 数 `v²/(gL)`、台阶高度/腿长）。两者不能混用；尺寸归一化不消除执行器性能差异。

## 6. 指标与输出

| 维度 | 示例指标/限定 |
|---|---|
| 任务成功 | episode 成功率、跌倒率、生存时间、距离、地形通过率、速度跟踪 RMSE；终止阈值预注册 |
| 学习效率 | 达标步数、学习曲线 AUC、训练方差、失败率、预算耗尽比例；不只最终 reward |
| 运动品质 | 步频、占空比、相位/对称性、足端滑移、落地冲击、最低摆动间隙、躯干角度/加速度；四足、人形有不同指标 |
| 电机与结构负载 | 扭矩/速度饱和占比、连续扭矩裕量、峰值持续时间、关节限位接近比例；没有热参数不推断温升 |
| 能耗代理 | 正机械功积分、净机械功分开报告；行进时机械 CoT=`E_positive/(m*g*distance)`；距离过小返回不可定义，不制造低能耗高分；没有效率模型不称电耗 |
| 稳健性 | 推扰恢复、摩擦/负载/质量/延迟变化下性能曲线；随机化范围和物理一致性必须记录 |
| 仿真数值 | warning、穿透、solver residual 可用项、非有限状态、引擎敏感性；问题先标模拟可信度 |

报告含逐 seed 曲线、分布/置信区间、配对差值（配对方案有效时）、原始数据下载、失败案例视频、代表性视频的选择规则和完整 run 索引。无共同任务版本/模型或配置缺失时禁止生成似乎公平的排名。

## 7. 从差距到 CAD 修改

归因图：症状 → 原始证据 → 候选原因 → 排除/验证试验 → 可修改参数 → CAD 部位。候选原因范围必须包含：导出错误、动力参数错误、控制/算法不适配、任务差异、机械设计限制、数据不足。

例：足端滑移较多可能来自摩擦设置、接触代理、奖励或质量分布，不能直接得出“腿太长”。先固定接触/控制条件检查，再单变量改变几何/质量并重新计算惯量，匹配训练预算，使用未见种子复验。只有仿真中的局部干预证据，不宣称实体因果已证明。

参数化修改保持物理一致性：长度变化时重算体积、质量、质心、惯量和关节 frame；电机更换同时改变执行器曲线和质量，禁止只增加 URDF effort 充当真实硬件升级。多目标选择在任务性能、重量、能耗、扭矩裕量、制造限制上形成 Pareto 建议。

每份建议包含：part/source path、link/joint UUID、当前值/建议范围和单位、坐标系、证据编号、预期影响、代价/不确定性、复验任务、状态 proposed/tested/rejected。导出 Markdown/HTML/CSV 和截图；SolidWorks 原始特征树不可恢复时只能提供零件/尺寸层面的修改说明与可导出的 STEP，不能声称自动写回原生工程。

## 8. Skills 设计

skills 目录由 `manifest.json`、`SKILL.md`、规则 JSON、测试夹具/反例、来源和变更记录组成。基础包：URDF 语义、坐标/单位、刚体惯量、关节/传动、接触/碰撞、动力学、实验公平性、统计解释、机械反馈。类型包：四足与人形。数据检索包：参照模型查找、实验检索、视频区段定位。

skill 声明输入前提、输出 schema、可调用的纯计算工具、受支持机器人类型、预估计算成本；规则加载时先 schema/版本校验。新 skills 可通过导入本地目录安装并回归测试。文献只能提炼方法和引用，不复制整本书/受限资料。外部 skills 无权新增付费 provider 或执行未列入能力清单的命令。

## 9. 评估器本身的验收

建立故障注入集：轴符号反转、mm/m 混淆、惯量 frame 旋转遗漏、负/非物理惯量、关节限位错误、漏网格、冲突 package、缺电机参数、偏置质心、碰撞粗化。正例包含合法固定 frame、中空形状、多 visual、非对角惯量和 mimic。记录检测覆盖与误报；仅在已标注集合上计算 precision/recall。

agent 验收要求所有结论引用真实 evidence id、缺数据会拒绝过度归因、对矛盾证据保留不确定性、不能编造视频/运行结果；同一报告应能由确定性工具复算主要数值。人工机械审查将作为后续校准来源，软件不能宣称替代实物测试和机械验证。
