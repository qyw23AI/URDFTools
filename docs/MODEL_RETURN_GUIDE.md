# 建模工作区 FreeCAD 回流

1. 在“建模”工作区生成参数化 CAD 版本，先完成 Link/关节配置。当前零件和装配版本保存在本机用户目录。
2. 在 FreeCAD 中修改相应实体并保存 `.FCStd`。回到建模工作区点击“比较 FreeCAD 回流”，选择该文件。程序通过本机 FreeCAD 转 STEP，显示零件重关联、体积/质心变化与冲突；原模型未被修改。
3. `review_required` 表示仅找到可关联的零件，仍需人工审阅差异。明确点击“接受回流并重新确认关节”后，新 STEP 与来源哈希被记录；旧建模版本继续保留，所有关节变为未确认。重新确认关节、驱动限值与密度后才预览/导出。
4. `conflict` 表示有新/丢失/歧义零件或面数/实体数变化。工作区不会应用；在 FreeCAD 中修正，或到“转换”工作区重新分组与确认关节。不能凭相同零件名忽略拓扑冲突。

接受记录在 Electron 用户数据目录的 `modeling/project/return.json`；启动时核对模型版本、STEP SHA-256 和配置来源哈希，无法验证时给出警告并回退到参数化版本。该记录不包括用户 FCStd 内容；保留原始 FCStd，且不要手改记录文件。几何回流不传递 FreeCAD 特征历史、材料真值和机器人电机参数。
