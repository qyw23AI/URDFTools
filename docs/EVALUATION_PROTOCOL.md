# 评估协议与金标准故障集 v1

2026-10-23。E00 规定 E01–E04 与结果对照层的判定边界。输入、证据层和外部训练结果协议见 `docs/EVALUATION.md`、`docs/RESULTS_DATABASE.md`。此文件是判定合同，不代表已经评估任何用户机器人。

## 1. 判定对象与证据等级

每条发现必须有 `rule_id`、规则版本、对象路径或 UUID、源文件哈希、观测值及 SI 单位、比较基准及出处、适用前提、置信依据、反例和复核动作。数值检查只返回 `pass|fail|unknown|not_applicable`，不得把缺字段记为 0，也不得把未知记为通过。

| 层 | 输入 | 可以判定 | 不可以声称 |
|---|---|---|---|
| E0 描述 | 原始 URDF、资源、单位声明、关节/连杆图 | 明确 XML/引用/拓扑/非有限数错误 | 机械设计差、真实惯量错误 |
| E1 物理 | 实测或 CAD 质量、质心、惯量、坐标 frame | 自相矛盾或与声明来源不符 | 仅凭 SPD 就称惯量真实 |
| E2 无训练探测 | 明确引擎、接触与执行器配置 | 特定配置下的编译、重力、关节与接触行为 | 任意 RL 算法的可训练性 |
| E3 外部训练结果 | 同任务协议的原始日志、独立种子、视频 | 该协议下的性能差异及不确定度 | 不同预算或算法结果的机械因果 |
| E4 复验 | 单变量 CAD/URDF 变体、相同预算外部复验 | 局部因果证据与反证 | 对实体可靠性的保证 |

结论置信级别：`definite` 表示自包含的格式或数值矛盾；`context_dependent` 表示必须有可信设计/测量 sidecar；`hypothesis` 表示由外部结果提出、尚需复验。严重度和置信度分开。规则可输出多条候选原因，必须列缺少的数据；一次训练失败只支持 `training_issue` 或假设，不能自动归因到 URDF 或机械设计。

## 2. 数值边界

长度、质量、惯量分别为 m、kg、kg·m²；不从视觉尺寸猜测 STEP/URDF 单位后静默修正。无 sidecar 的大/小尺寸只能给 `scale_suspect` 提醒，不给确定“误单位”；`context_scale_mismatch` 要比较同一设计对象和可信原始尺寸。

在惯性原点为质心且 frame 对齐后检查对称、有限、主值非负和三角不等式。正定仍可能不满足三角不等式；这些是“可能物理有效”的必要条件，不能证明质量分布真实。[Drake 的惯量判定](https://drake.mit.edu/doxygen_cxx/classdrake_1_1multibody_1_1_rotational_inertia.html)明确给出主值与三角约束及其非充分性。容差随惯量尺度变化，不能用固定绝对阈值把微型机器人全部误报。若惯量参考点不是质心，先用平行轴定理移回质心；未知 origin 时只报资料缺失。

固定关节连接的无惯量传感器 frame 是合法描述，不能按动态刚体缺质量规则报错。移动关节的实体若缺惯量，则输出 `missing_data` 并阻止依赖动力学的结论；模拟器可能合并固定 frame，编译结果要保留映射和损失记录。[ROS urdfdom 的可选惯量讨论](https://github.com/ros/urdfdom/issues/138) 与 [MuJoCo 的 URDF 编译说明](https://mujoco.readthedocs.io/en/stable/XMLreference.html)支持将解析语义与模拟器行为分别记录。空腔中的质心并不违反物理；需检验质量分布和惯量，而不能要求质心位于某个视觉三角形或实心碰撞体内。

关节轴零向量是确定错误。非零轴的方向语义须由关节 frame 与设计 sidecar 或可复算运动学对照；不能只凭关节名称猜左右腿轴。碰撞代理的外形/体积不能替代有材料的 CAD 惯量；URDF effort/velocity 不能替代完整电机曲线。

## 3. 可比性与复验

外部训练结果先核对机器人资产 hash、算法版本、任务/奖励、引擎与 solver、时间步、控制频率、动作/观测映射、执行器/接触、预算、地形种子、独立训练种子和评价协议。输出 `matched|conditional|incomparable|insufficient_data` 及逐字段理由。不同 reward 定义不得按 reward 排名；视频帧或同一策略多个 episode 不算独立训练种子。标准模型库和标准训练结果库分开，夹具永不晋升为真实参考成绩。诊断先排查导出、控制、仿真和数据缺项，再提出 CAD/URDF 修改假设；修改方向需附外部复验计划。
