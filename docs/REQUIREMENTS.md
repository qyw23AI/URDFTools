# URDFTools 需求基线

日期：2026-10-22（Asia/Shanghai）。本文件记录用户授权的产品范围；设计已足够启动开发，不需要再等待架构审批。

## 交付目标

在 `/home/qyw/URDFTools` 开发面向强化学习机器人研发的桌面应用、Python 工具包、CLI 和 agent 工具接口。主界面使用中文，专业术语可保留英文。先支持本机 Ubuntu 22.04 x86_64，最终打包成可启动应用，安装 `.desktop` 并追加到 GNOME 收藏夹，保留现有收藏项。开发按阶段推进，完成设计后由项目调度器真正启动不同模型实现。

## 需求编号

| 编号 | 用户需求及验收含义 |
|---|---|
| R01 | 拖入 URDF 文件夹、文件或 ZIP；自动发现多 URDF 并供选择；正确解析 mesh/package 路径、中文路径、材质；显示丢失资源而非空白成功。 |
| R02 | 查看 link/joint 树、关节滑块与限位、视觉/碰撞体、坐标轴、质心/惯量、测量、视角、姿态、动画、截图；交互简单。参考 gkjohnson URDF loader 和 Robotsfan Viewer。 |
| R03 | STEP/STP 等 CAD 导入、零件分组为刚体、关节定义/建议、质量/惯量/网格计算、手动修正、可复用转换配置、一键导出自包含 URDF 包。参考 StackForce CAD2URDF 并检索开源替代。 |
| R04 | 支持参数化 CAD 绘制及 URDF link/joint 编辑；agent 可辅助创建/修改，人工预览和微调，撤销重做和版本差异可见。 |
| R05 | 接入大模型，工具和 skills 可扩展；默认使用现有 Codex ChatGPT 登录，可另接已配置的本地模型。未获明确授权不得激活额外付费 API。 |
| R06 | 判断 URDF 是否适合指定 RL 训练任务；分别输出描述文件缺陷、物理/机械风险、仿真设置风险、训练不确定性，给出证据和修改方向。 |
| R07 | 四足、人形分别建参照库；首批目标 A1、Go2、G1、H1。许可允许时固定版本取得模型；不把知名机器人自动认定为所有任务的最优设计。 |
| R08 | 建立机器人动力学和机器人类型 skills 库，包含可运行规则、来源、单位、适用范围、反例、版本；后续可添加。 |
| R09 | 导入用户在外部平台用标准/自有 URDF 得到的训练曲线、指标、种子、配置和视频；建立按机器人类别/算法/任务索引的标准结果库，同条件比较步态和地形能力。本工具不实现训练。 |
| R10 | agent 调用证据及 skills 解释差距，区分可能原因与经消融验证的原因，反馈到具体 URDF link/joint 和 CAD 零件/参数，供机械组在 SolidWorks 等软件改进。 |
| R11 | 2026-10-22 用户更新：停用本地 Python/systemd 开发调度器；Codex 每小时心跳在本对话检查额度与 WebCodex 活跃状态，直接复核、改进、验收并继续下一阶段。保存文档与 Git；提交暂时受阻时保留改动继续开发。 |
| R12 | 节约额度：每小时任务先检查当前账号主窗口和周窗口剩余额度，任一不超过 5% 时暂停本轮模型开发；按任务复杂度选择当前账号允许的模型与思考强度，不启用额外付费 API，也不把模拟执行、占位实现或未跑的训练标作完成。 |
| R13 | 最终应用安装、打包、使用说明、第三方许可、真实验收材料均齐全；所有必需阶段完成才可称全部交付。 |

## 已采用的默认范围

- 首批任务：站立/平衡、平地速度跟踪、转向、坡面、台阶/障碍、推扰恢复；四足与人形各自配置，不混排单一排行榜。
- MuJoCo/Pinocchio 仅用于可选无训练物理探测。SB3、RSL-RL、Isaac Lab 等通过结果文件适配，不安装其训练器。
- 参考数据来自用户上传或来源/许可可核验的公开结果；软件可验收空库/导入流程，真实数据覆盖单独记录。不得把 synthetic fixture 冒充参考训练成绩。
- SolidWorks 原生装配提取需要 Windows + SolidWorks 的导出桥，Ubuntu 支持导出后的 STEP/URDF/graph 包；不承诺无依赖直接读取所有专有 CAD。
- 每个已授权开发阶段内允许本地安装项目依赖、读取官方源、获取有许可的开源代码、运行测试和本地 Git 提交。禁止自动购买额度、兑换额度重置、调用新增付费 API、发布远程仓库或修改系统 GPU 驱动。
- 应用仅生成外部复验建议和数据模板；训练由用户的外部平台完成后再次导入。本地后台作业限于导入、媒体和分析，资源有界、可取消恢复。

## 当前机器观测

Ubuntu 22.04.5 / GNOME；24 逻辑 CPU、约 30 GiB 内存；观测时可用内存约 6 GiB；剩余磁盘约 631 GiB。`nvidia-smi` 无法连接驱动，因此 GPU 能力为未知/不可用，不能据此断言没有 GPU。

系统 Python 3.10.12；Codex 自带 Python 3.12.14 和 Node 24.19.0 可用于开发引导（路径见 `OPERATIONS.md`）。发行包必须使用自己的可复现运行时，不依赖 Codex 缓存目录。
