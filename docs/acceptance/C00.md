## 限制与剩余风险

- C00 交付的是 STEP 读取、装配树、单位/颜色/变换/来源追溯原型，**不是完整 CAD→URDF 转换器**。尚未实现关节推断、CAD 坐标系编辑、网格导出、URDF 生成、转换预览 UI 或一键导入查看器。
- 当前显式验证毫米和米。其他或混合长度单位会报告 `ambiguous_or_unsupported` 并附警告，不会静默假设为毫米；需要增加英寸/英尺等单位测试后再承诺支持。
- B-rep 包围盒是几何范围，不是 CAD 设计意图；step2urdf 适配器返回的体积/惯量相关内部值不应直接视作质量、真实密度或强化学习物理合理性结论。
- 未验证 FreeCAD GUI、用户实际 GNOME/GPU 环境、超大装配性能、外部 RL 训练结果分析；没有启动 RL 训练器或修改调度器状态。
- 本记录报告的是技术 gate 结果。按照 `tasks/C00.md`，是否将阶段标记完成由调度器复核；本轮没有修改 `.scheduler/state.json`，没有 Git commit/push。
