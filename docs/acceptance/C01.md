## 实现范围

- 新增 API：urdftools.cad.calculate_solid_mass_properties、transform_mass_properties、rotate_inertia_tensor、aggregate_mass_properties、compute_step_mass_properties，位于 python/urdftools/cad/mass_properties.py。
- 新增 CLI：scripts/cad_step_mass.py。必须显式传入统一密度 --density 或按精确零件名传入 --densities-json；不提供密度时只报告可确定的几何体积/几何质心，质量与物理惯量保持 null。
- 质量属性仅来自 STEP B-rep 实体。开放壳、适配器标记的近似几何和 OBJ/URDF visual/collision mesh 不会被当作真实质量来源。
- 采用 OCP 的闭合有效 solid 体积属性，按单位转换计算：\(V_{m^3}=V_{mm^3}\times10^{-9}\)，\(m=\rho V\)，\(I_{kg\,m^2}=I_{mm^5}\rho\times10^{-15}\)。
- 局部到世界坐标使用 \(c_w=Rc_l+t\)、\(I_w=RI_lR^T\)；装配总惯量按平行轴定理合成到总质心。
- 任何零件材料密度缺失、几何不支持或密度分配名称不匹配时，整体总质量/质心/惯量保持未知；已知质量仅作为 subtotal 报告，不把缺失零件当成 0 kg。

### 长方体：独立解析公式对照

- 输入 box_mm.step SHA-256：a0e9f5c79f5cc80edb530a696f2d0e48e46dd133be919be86a0db2dee121e656。
- 几何尺寸 20×10×5 mm，密度 1000 kg/m³；体积约 \(1.0\times10^{-6}\,m^3\)，质量约 **0.001 kg**，质心 (0.01, 0.005, 0.0025) m。
- 三个主惯量分别约 \(1.0416667\times10^{-8}\)、\(3.5416667\times10^{-8}\)、\(4.1666667\times10^{-8}\,kg\,m^2\)，与长方体闭式公式一致。

- 两个半径 10 mm 的球心分别位于 x=0 与 x=50 mm，密度均为 1000 kg/m³；总质量约 **0.00837758041 kg**，总质心 x=0.025 m。

### 旋转长方体：非对角惯量与坐标变换

- 输入 rotated_box_mm.step SHA-256：d9a27532972889b9db46cef5b8eb37250c8cb8f73f7d53e80a264e32dc7914cf。
- 20×10×5 mm 长方体绕 Z 轴旋转 45°，再平移 (100, -20, 30) mm；密度 1000 kg/m³，质量约 0.001 kg。
- 世界质心为 (0.1035355339, -0.0093933983, 0.0325) m；\(I_{xy}=I_{yx}\approx-1.25\times10^{-8}\,kg\,m^2\)，证明旋转后保留非对角项。通过同一输入的局部 B-rep 属性与 4×4 变换 API 交叉比较。

### 材料缺失与失败安全

- 未指定材料时，零件 mass_kg 与 inertia_com_kg_m2 为 null；装配总质量、总质心和总惯量也为 null，附带 material_density_missing 与 assembly_mass_incomplete。
- 部分零件有密度时只报告已知质量小计，并列出未知零件；整体结果不被误标为完整。
- 密度分配到不存在的零件名时报告 unmatched_density_assignments；非正密度被拒绝。
- 近似几何不参与质量/惯量；.obj 输入被拒绝，明确不把 visual/collision mesh 当作物理质量。
