# URDF 工作区合并验收（2026-10-24）

本轮按用户修订将顶部「查看」「建模」合并为「URDF 工作区」，保留原 Three.js 查看器的结构、关节、测量、显示、物理与截图能力。顶部按钮按需打开代码、CAD 模块库、Agent CAD 浮动面板；新面板沿用原 `FloatingPanel`，可拖动及半屏放大。切换到转换或评估再返回时保留工作区状态。

- 点击关节点或结构树 Joint/Link 后，代码面板打开并选中对应 XML 元素。编辑可校验并生成新的本地导入版本，支持会话内撤销/重做；删除选中 Link 或 Joint 时删除其子树，根 Link 受保护。导出 ZIP 包含 URDF 与所用网格资源，源文件不被修改。
- CAD 模块库持久保存导入的 STEP/STP/STL/OBJ 模块。STEP 经项目固定的 build123d 转成实际 STL 几何；STL/OBJ 由用户选择原始单位。模块可拖入三维场景，也可点击添加。新模块先显示在场景内，依次点击原模型与新模块表面，选择固定或连续旋转连接，再确认。中心点按钮提供键盘/单指替代。连接点与表面法向用于计算 URDF joint origin。
- Agent CAD 面板复用项目已有网页 ChatGPT/WebCodex 或当前账户 Codex CLI 的人工请求、建议预览和确认流程。当前 CAD 或确认生成的 CAD 可转为真实网格并加入模块库。Agent 不自动提交模型变更。
- 新增 Electron IPC 仅接受当前渲染窗口调用；URDF 引用资源来自导入清单，复制前复核 SHA-256。XML 拒绝实体与 DTD、重复名称、断开的根以及关节环；导入工作流再次校验输出。CAD 模块不推断质量、惯量、碰撞或电机参数。

验证：TypeScript/Vite 构建与 React shell 2/2；Python 实际 C01 STEP→STL→URDF 编辑→两次重新导入及异常图拒绝 3/3；隔离 Electron 39.2.7 从内置模型开始，实际点击关节定位代码、编辑并保存、导入真实 STEP、DragEvent 拖入、选中心点连接、导出 ZIP、进入 Agent 面板生成起始 CAD 并确认第二个条目入库，最后切到评估页，进程退出 0。导出 ZIP 再次通过导入器校验：1 个 URDF、5 个资源、0 finding。截图与完整日志见 `artifacts/URDF_WORKBENCH_2026-10-24/`。

限制：桌面验收通过程序事件验证拖放和中心点连接，尚未对用户真实 A1/Go2 模型手动逐面点击复验；真实 AI 回复质量沿用 D03 的独立验收，本轮未调用外部模型。CAD 可视模块缺少实际材料/惯量/碰撞时仅适合构型预览，不能据此视为动力学或训练就绪。撤销/重做历史在当前会话内；跨会话请导出 ZIP。原 M00/M01 的复杂参数化 CAD 界面退出顶部导航，旧验收脚本中直接寻找「建模」标签的步骤需按修订后的 Agent 面板重写后再跑正式阶段 gate；本轮不宣称这些历史阶段 gate 已重新通过。
