# S05 查看器分析工具验收 — 2026-10-22

**实际阶段 gate：2/2 通过，0 skip；`scripts/accept_phase.py S05` 退出码为 0。** S05 已具备可运行的查看器分析工具，但这不代表整个 URDFTools 应用已经交付。

## 已实现

- **结构树与定位：** 从 URDF 的 joint parent/child 关系构建 Link/Joint 层级；选择节点后相机定位到对应 Link 的视觉包围盒中心或 Joint 世界坐标。
- **显示与隔离：** 视觉模型、Collision 碰撞体、显式质心标记分别控制；可以隔离选中的 Link、解除隔离、重置视角。它们只改变当前三维场景，不改写导入文件。
- **质量、质心与惯量：** 直接读取源 URDF 显式声明的 mass、inertial origin xyz 和 inertia 张量；显示质心局部/世界坐标。缺失字段显示“未知”，不把 `urdf-loader` 的默认零值当作源参数。仅当所有 Link 的质量与质心位置均明确可用时才计算整机质心。
- **几何测量：** 显示整机视觉包围盒与选中 Link 的视觉包围盒尺寸，并随关节姿态更新。此测量来自加载后的三维几何，不是 CAD 精确尺寸。
- **关节与截图：** 保留 S04 的关节滑块和 URDF 限位；支持导出当前三维画布 PNG。

## 限制与后续风险

- 测试数据是 `tests/fixtures/S05/simple_robot/` 内的原创合成夹具，不是用户真实四足机器人或 Go2/G1 的模型。尚未对复杂、超大、多 package、特殊材质/坐标约定的真实模型进行人工验收。
- 包围盒受 mesh 单位、缩放和模型几何影响，只能用于快速检查；不能替代 CAD 尺寸或碰撞几何精度检查。
- 本阶段展示 URDF 中的惯量张量原始分量，不验证正定性、物理合理性或机器人动力学一致性；缺失参数保持未知。完整物理规则、CAD 转换、Agent、训练结果评估和发行安装仍属于其他阶段。
- headless Electron 日志会出现当前环境的 D-Bus / VAAPI 初始化警告；本轮声明断言均通过。软件 WebGL 结果不能作为独显性能基准。
- 未运行强化学习训练、未修改调度器状态、未创建 Git commit。
