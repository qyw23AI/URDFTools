# B06 外部日志适配与本地交换验收

2026-10-23。实现固定版本 `sb3-csv-v1`、`rsl-tensorboard-v1`、`isaaclab-tensorboard-v1` 与 `mlflow-local-metrics-v1`；只读用户提供的日志字节，不调用 SB3/RSL-RL/Isaac Lab 训练器、MLflow 服务器或 checkpoint。SB3 CSV 的 timesteps、平均 episode reward/length、fps 映射到统一标量；RSL-RL/Isaac Lab TensorBoard tag 用白名单映射，未映射 tag/列在 `unmapped_fields` 明确列出，原始日志 SHA-256 保留。统一 CSV 通过 B00 内容哈希导入与 B01 数值/单位事务入库。MLflow 本地 `metrics/<name>` 三列时间毫秒、值、step 文件可导出再导入，路径名受限，不覆盖既有目录。

正式 `.venv/bin/python scripts/accept_phase.py B06` **1/1 gate、2 项测试、0 skipped**：SB3 格式 CSV `time/total_timesteps=100`、reward 2.5、episode length 12 转成 B01 两条数据，未知 `train/custom` 列记录丢失；使用 TensorBoard 官方 `EventFileWriter` 真实生成 RSL 风格 reward=3.5@20 及 Isaac Lab 风格 success=0.5@21 的二进制 Event，各自进入 B01。MLflow 本地一条 0.75@step2、wall time123.25 的标量往返数值和时间一致；不支持的适配版本明确拒绝，危险指标名拒绝。证据 `artifacts/acceptance/B06.json`、`artifacts/B06/runs/`。

格式依据：[SB3 官方 logger 文档](https://stable-baselines3.readthedocs.io/en/master/common/logger.html)、[Isaac Lab 官方 RL 日志说明](https://isaac-sim.github.io/IsaacLab/main/source/overview/reinforcement-learning/rl_frameworks.html)、[RSL-RL 官方 logger 配置](https://github.com/leggedrobotics/rsl_rl/blob/main/docs/guide/configuration.rst)、[MLflow 官方本地后端说明](https://mlflow.org/docs/latest/tracking/backend-stores/)。测试的 SB3 CSV 是按字段格式自制的合成日志，没有安装或运行 SB3；TensorBoard Event 是真实官方写入器生成但数据仍为合成。MLflow roundtrip 是本项目实现的本地指标交换格式，未由 MLflow 客户端互操作验证，因此不宣称兼容所有 MLflow 版本。没有真实用户训练结果或 GPU 训练。
