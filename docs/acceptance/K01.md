## 实现与证据

- `python/urdftools/evaluation/quadruped.py`：只读、限制 XML 大小和 DTD/实体的四足分析器；基于真实 URDF 父子链识别 FL/FR/RL/RR 的 hip/thigh/calf 三自由度，检查 12 DOF、足端碰撞、关节轴/上下限、URDF effort/velocity。缺失电机参数报告 `unknown`，非正数才报告 `fail`；**URDF 声明的 effort 不是电机扭矩-转速标定曲线**。
- 通过关节原点、RPY 和绕关节轴旋转的 FK，计算各关节限位中点的四足投影凸包面积；这是几何分布检查，**不是可站立姿态、重心稳定性或步态证据**。缺乏真实电机/动态数据时明确报告 `motor_calibration=unknown`、`dynamic_balance_and_gait=unknown`。
- 可选的显式 `contact_trace`（`source_kind`、`frame=world`、单调 `t_s`、COM/足端 XY 和接触腿）对**提供的**时序数据做准静态投影和接触切换检查；两足接触或退化支撑多边形返回未知，COM 超出多边形仅表示准静态投影不满足，不断言跑动会跌倒；`gait_quality_status` 始终未知。调用者声明的来源不等于验证过的来源。
- `skills/builtin/quadruped_structure/manifest.json` 通过 K00 安全白名单调用；输入为显式 URDF XML 文本，不读取任意用户路径、不运行插件代码。结果包含来源 SHA256、逐项状态、未知项与限制说明。
