限制和剩余风险：

- 解析/保存的是领域 JSON；未实现或宣称 URDF 文件夹/ZIP/XML 导入导出、几何/动力学、
  GUI 集成或跨进程/数据库事务。它们仍按后续任务实施。S01 GUI/干净安装本轮未重跑。
- v1 是本阶段明确保留的旧布局 fixture，不声称兼容不存在的历史用户文件；
  ProjectManifest 尚无历史版本输入，因此没有编造其迁移样本。
- 冻结为正常 Pydantic API 和只读 TS 范围；不是对进程内任意 Python 代码的安全隔离。
  内存历史不提供多线程/多进程互斥，文件保存是原子单文件替换，不是多文件数据库事务。
- 路径解析与读取之间没有目录描述符锁定；并发恶意替换文件/符号链接的竞态不在本阶段
  已验证边界。未来对外文件导入服务必须落实其独立沙箱与并发访问限制。
- 保存文档/快照不自动拷贝或锁定资产，调用方须用 verify_asset 核对实际字节。
  Schema 合法不代表物理可信；没有计算惯量正定、FK 或仿真。
- 全部输入为原创 fixture，真实参考结果覆盖为 **0**；不运行训练器、不加载策略权重、
  不给出机械因果结论。无 GPU 参与，本阶段没有硬件阻塞。
