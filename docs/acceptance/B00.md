# B00 外部结果导入作业验收

2026-10-23。实现 `urdftools.results.jobs.ImportQueue`：SQLite WAL 中的作业、租约、分块偏移、已完成 run 与资产索引；大文件以 SHA-256 存本地内容地址目录。导入只读取用户外部实验数据，不运行训练器、策略权重或上传远端。一个 `bundle_id` 固定对应源目录、完整 manifest 和机器人 SHA-256；同 ID 变更模型或文件清单立即拒绝。路径穿越、最终符号链接、缺失文件、大小与哈希不符拒绝。源文件保持原样；未完成全部文件前不发布 run。取消后不得被重新领取。

正式 `.venv/bin/python scripts/accept_phase.py B00` **2/2 gate、0 failed、0 skipped**。3 项单元覆盖部分字节检查点、租约夺回、同包幂等、机器人哈希冲突、路径穿越/链接、坏文件不发布、取消。`scripts/b00_crash_smoke.py` 用真实子进程导入约 600 KiB 外部指标 CSV，在 1000 字节检查点后 `SIGKILL`，确认数据库中尚无 run；模拟租约到期后用第二进程续传，最终 1 run、1 asset、字节与源数据相等。同包重复入队仍返回原 job。首次 gate 因测试的源码路径未插入 Python path 失败，修正后复跑通过；两次完整日志保留在 `artifacts/B00/runs/`，最新摘要 `artifacts/acceptance/B00.json`。

范围：这是后台导入基础层，只识别通用文件 inventory、bundle ID 与 robot hash；B01 才实现外部训练结果 manifest 的协议/单位/媒体语义。没有实际用户数据、真参考成绩或视频分析。当前 worker 的失败状态保留错误，取消保留已有孤立 blob 供后续 GC；尚未实现磁盘配额、源目录被恶意并发替换时的完整 openat 隔离、作业 UI 与自动化监控。崩溃测试使用短租约手动设为过期以避免等待 30 秒，不把这当作认证/额度行为。
