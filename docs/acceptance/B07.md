# B07 外部视频时序与交互对照验收

2026-10-23。PyAV 只读解码用户本地视频，记录 episode、相机、原始 SHA-256、帧 PTS、偏移、帧率差异、变帧率和疑似缺帧索引；按实验时间与视频偏移定位指标事件，超出视频范围明确返回 outside。CLI `scripts/b07_media_report.py` 可生成供桌面界面读取的 JSON 侧车；评估工作区可选择本地视频/报告、显示警告并点击事件跳转到帧。前端用 WebCrypto 核对不超过 128 MiB 的视频 SHA，错误文件禁用事件定位。CSP 仅为媒体增补 `blob:`，脚本/联网源限制未放宽。视频无法给出扭矩和能耗值。

正式 `.venv/bin/python scripts/accept_phase.py B07` **2/2 gate、2 项真实编解码测试、0 skip**。PyAV 编码 5 帧视频且特意缺少一帧，真实解码观察到时序间隔、疑似 gap 索引 3；偏移 4 s 的事件准确定位 frame 3，越界事件单列。无效媒体和 episode 错配被拒。正式桌面 gate 先用项目固定 Node 工具链生产构建，再生成本地 WebM/报告，在 Electron 39.2.7 无头实例加载，视频 SHA 匹配、浏览器实际可解码、缺帧警告可见、点击 fall@5.4 s 后视频定位到约 0.49 s 的第 3 帧，保存 `artifacts/B07/desktop/media-view.png`。正式日志与机器摘要见 `artifacts/B07/runs/`、`artifacts/acceptance/B07.json`。

首次桌面烟测因页面 CSP 未允许 `blob:` 媒体源，Chromium 返回 `MEDIA_ERR_SRC_NOT_SUPPORTED`；增加专用 `media-src 'self' blob: urdftools:` 后复测通过。最初失败日志在调试时被桌面脚本覆盖，正式 gate 的日志保留；不将失败迭代说成首次通过。PyAV 固定版本见 `requirements/results.txt`，没有改系统 Python/GPU 驱动。

限制：当前交互用用户手动选择的视频与 JSON 侧车，未直接从 B01 数据库列出素材；超过 128 MiB 的文件因浏览器整文件哈希内存限制暂不允许事件定位。合成视频和指标只验证对齐流程，不是机器人训练视频。变量帧率、缺帧只是时间戳提示；用户仍需核对相机同步，普通视频不能反推出力矩、质量或能耗。后续 B08 再做两类机器人结果包端到端流程。
