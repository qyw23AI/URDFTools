## 限制与未完成

- 只验证所选两个版本的 Go2 和 G1，并不意味着任意 URDF/Xacro/复杂纹理/扩展 CAD 文件、真实 3D GPU 加速均正常；未读取或重写用户四足真实 URDF。
- 实验截图来自 headless SwiftShader 软件 WebGL；D-Bus/VAAPI 环境警告不能用来推断真实 GPU 性能。DAE 只校验 XML 结构，不能保证三角面片拓扑、网格物理属性与训练碰撞一致。
- 碰撞线框可视化不等于机器人自碰撞检测；惯量数据仅为源 URDF 声明，未验证正定性或力学合理性。实际验证由后续评估阶段进行。
- Go2/G1 上游固定提交与资产及许可证可追溯，**最终再分发、打包体积和开源 NOTICE** 仍在 Q01 审查范围内。这里的临时 ZIP/源码副本不自动打包发布。
- 无本地 RL 训练器；未修改 scheduler/timer/state，未进行 Git commit 或正式 GNOME 安装。
