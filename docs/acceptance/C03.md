### 2026-10-25 Link 创建即建立 Joint

创建 `base_link` 后，创建每个子 Link 时先选择父 Link；界面立即生成 `<子Link>_joint`，显示在 Link 结构中，点击后打开对应 Joint 设置栏。改父 Link 会同步更新 Joint 并撤销原有确认。Joint 栏现在可编辑名称、父 Link、类型、旋转角度限位（度，内部保存弧度）、轴向/位置、最大力或力矩与速度；可自动重新识别、两点设轴、反转轴向、试转并确认。自动轴优先匹配父子零件的同轴圆柱面；缺少成对证据时只给估计位置并要求人工核对。画布在当前 Joint 位置显示红色环和蓝色轴向箭头。
