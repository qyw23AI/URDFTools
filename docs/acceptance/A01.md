# A01 Agent 辅助建模验收

2026-10-23。Electron 建模工作台新增自然语言指令、真实 ChatGPT/Codex 建议、隔离 CAD 预览、参数与质量差异、拒绝、人工接受和复制到编辑器微调。建议只读当前已保存的配方和版本；Python bridge 通过 A00 白名单构建预览，接受时重新校验版本与预览配方哈希，再生成不可变 CAD 版本和 STEP 装配。普通建模撤销可恢复旧配方并生成下一版本。模型没有直接应用入口。

独立真实 CLI 双连杆试验：只要求 Arm 宽度 30→40 mm，Base 保持不变；拒绝后工程指针字节不变，接受后版本 1→2、Arm 质量 0.003744→0.004992 kg；重新生成 STEP、导出 URDF/ROS ZIP，独立仿真校验为 2 Link/1 Joint；撤销后版本 3 的 Arm 体积与质量恢复。最初测试以 STEP 字节哈希判断撤销，跨分钟导出不稳定导致失败，已改为体积/质量数值断言，保留原失败记录于本说明，不把它当产品故障。

真实 Electron headless/offscreen 试验：从空项目创建两零件和关节，实际导出原始 URDF；页面输入建模指令，生成建议并展示 diff/预览质量；拒绝后仍为版本 1，再生成建议并接受后为版本 2，页面撤销并重建为版本 3。首次 UI 测试脚本的正则转义错误误判拒绝，已改为直接检查版本文字后通过。截图、完整日志和机器报告在 `artifacts/A01/desktop/`。TypeScript 编译与 Vite 生产构建通过。

正式阶段命令 `.venv/bin/python scripts/accept_phase.py A01` **2/2 门禁通过，0 失败，0 跳过**；机器记录见 `artifacts/acceptance/A01.json` 和 `artifacts/A01/runs/`。真实 Codex 额度或认证不足时，该 gate 保持失败而不使用付费 API 回退。

限制：本阶段只用原创合成双连杆进行真实模型试验；模型设计建议仍需机械组审阅。接受新几何后关节和材料确认需重新检查。STEP 几何和 URDF 结构验证不证明机器人可训练性或实物性能。更广泛的 CLI/MCP 接口属于 A02，复杂用户 CAD 与真实大模型质量评估仍待后续阶段。
