# E04 — 无训练 MuJoCo CPU 动态探测验收（2026-10-23）

**探测工具验收：2/2 gate 通过、4 项实际仿真测试、0 skip。不是机器人站立/训练成功。**

## 实施
scripts/e04_sim_probes.py 在本机 MuJoCo 3.16 CPU 上执行有界的 0.002 s 时间步、每项 1200 步探测：
- 固定基座解析双连杆单关节阶跃（肩关节目标 0.4 rad、肘关节 0 rad），PD=35/6，显式重力补偿、最大关节 25 N·m；末态误差 7.61e-8 rad。
- 同一 URDF/hash、错误负阻尼 PD=35/-6，误差 2.687 rad。按同模型不同控制器分类为控制配置问题，不归因机械/URDF。
- 正确 PD 下 2 N·m、0.1 s 短脉冲扰动后恢复，误差 7.18e-6 rad。
- 独立自由球体实际落地接触，1066 个接触时间步，球心静止高度约 0.04963 m；25 关节采样质量矩阵最小特征值保持正。
- 完整浮动基座原创四足（14 nv，11.2 kg），8 个关节 PD 锁定与地面接触仿真。观察到接触、随后姿态失稳，分类 unstable_in_this_probe，**绝不宣称四足站立稳定**。该失败可能受形状、接触代理、控制器或求解器影响，需复验定位。

生成 artifacts/E04/probe-report.json（每 20 步的时序 qpos/qvel/torque/触地或浮动基状态，仿真来源哈希及条件），artifacts/E04/two_link_probe.urdf 和 floating_quad_ground_stance.urdf；媒体 artifacts/E04/two_link_state_replay.gif 为从真实 MuJoCo qpos 绘制的 **160×160、30 帧二维示意动画**，不是引擎相机渲染，也不是硬件摄像头视频。
