# E02 — 双连杆动力学一致性验收（2026-10-23）

**正式结果：2/2 gate，3 个数值测试，0 skipped。**

## 完成与真实计算
- 新增独立解析 PlanarArm 双连杆质量矩阵 M(q) 与势能重力项 G(q)，参数均为明确 SI：长度 0.4 m、质心偏置 0.2/0.15 m、质量 2/1 kg，转动惯量与长方体解析式一致。计算无引擎依赖。
- 脚本 scripts/e02_dynamics_smoke.py 构造原创双连杆 URDF、反向安装的肘关节 frame 变体、无惯量 fixed IMU frame 变体；真实调用 MuJoCo 3.16 CPU API 对 4 个关节姿态计算 fullM 和 qfrc_bias。
- 正常模型最大质量矩阵绝对误差 1.11e-16 kg*m²、重力项误差 8.88e-16 N*m；固定 frame 质量矩阵误差同量级且 DOF 不变（2）；错误肘关节安装产生 0.24 kg*m² 质量矩阵差异和 6.15 N*m 重力偏差，被独立侧证识别。
- tests/e02/test_dynamics.py 另以势能差分验证解析 G；正定、对称、错 frame/fixed frame 和 SHA-256 均实测。
- 首次运行 E02 因本地 MuJoCo 3.16 将 data.qM 改为 data.M 的 mj_fullM(m,d,output) 签名失败；已改用该版本正确 API 并重新通过。
