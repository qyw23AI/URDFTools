# K02 — G1/H1 人形结构与准静态支撑技能（2026-10-23）

## 实现

新增 python/urdftools/evaluation/humanoid.py 与 skills/builtin/humanoid_structure/manifest.json，经 K00 JSON 白名单工具 humanoid_urdf 执行。输入为显式 URDF XML 字符串，不读取任意用户路径、不执行代码、不修改厂商源文件。限制 4 MiB XML，拒绝 DTD/实体；检查树、名称、G1 29/H1 19 个可动关节、两侧 hip/knee/ankle 运动链、轴/限位/effort/velocity 声明与足底碰撞。碰撞几何的局部 XY 面积只是几何代理，不是实际接触面。

逐 Link 检查正质量、惯量主矩非负与三角不等式（有限精度容差）；求声明惯性标签质量和，q=0 根坐标系质心估计。缺失惯性标签的固定传感器 Link 不被当成零质量，因此质心标注 unknown。此计算不代表硬件称重或 MuJoCo 固定根融合质量。

可选 contact_trace 必须声明 source_kind、frame=world、递增 t_s、COM XY、左右脚世界系多边形与接触集合。仅计算准静态 COM 投影，点接触/退化多边形为 unknown；可统计躯干 RPY 峰值和膝踝相对 URDF 声明限位的越界。动态平衡、步态质量和电机实际能力始终 unknown；准静态投影失败不等于动态必然跌倒。source_kind=measured 只是调用者标签，未核实来源。
