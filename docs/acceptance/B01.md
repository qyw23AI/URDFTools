# B01 外部实验结果格式与规范化入库验收

2026-10-23。B00 导入完成且全部原始文件通过 SHA-256 后，`ResultCatalog` 才读取包内 `experiment.json`，解析 CSV、JSON、Parquet、TensorBoard Event 原始 scalar；不调用用户脚本、不反序列化策略权重或 pickle。每条标量保留 run、metric、step、value、wall_time、单位、原始文件 SHA-256 与行号。结果和实验元数据在同一 SQLite 事务写入；有坏行时不发布部分规范化结果。相同 job 重试幂等，另一 bundle 复用 run ID 拒绝。

输入约定：`experiment.json` schema v1 含 `run_id`、`robot_hash`、`robot_category`、`algorithm`、`protocol`、`origin`、`metrics:[{path,format,units}]`。可选的算法版本/commit、协议版本、许可证和引擎名为 `null` 时记录 `missing_json`，不能猜测。旧版 v0 的 `robot_sha256/name/task` 显式迁移到 v1 规范字段，并同时保存源版本与原始 v0 文件哈希。来源为 `synthetic_fixture` 的烟测不会成为 verified reference。

正式 `.venv/bin/python scripts/accept_phase.py B01` **2/2 gate、4 项单元、0 skip**。`scripts/b01_format_smoke.py` 自行生成四种真实格式，均得到 step=12、value=0.75 ratio、wall_time=123.25 的同一条指标，4 run/4 行；单元覆盖 v0→v1 原始文件保留、NaN、缺失单位、坏资产 SHA、重复 run、pickle 格式拒绝及缺项清单。首轮 TensorBoard 使用迁移读取器时漏掉旧式 `simple_value`，改为直接读取官方 `LegacyEventFileLoader` 原始 Event 后通过，历史手工失败记录未写入正式 gate；正式日志在 `artifacts/B01/runs/`，机器摘要 `artifacts/acceptance/B01.json`。

依赖锁见 `requirements/results.txt`：隔离 Python 3.12 虚拟环境，PyArrow 26.0.0 与 TensorBoard 2.20.0，以及精确固定的传递依赖。安装时使用公开 PyPI，不启用付费 API；`env -u PYTHONPATH .tools/results-venv/bin/python -m pip check` 返回无破损依赖。PyArrow 与 TensorBoard 均为 Apache-2.0，发行包仍须在 Q01 汇总所有传递依赖许可和来源。

限制：只导入标量，视频/episode 时序对齐、训练条件可比性、参考等级审核分别属于 B07/B05/B02–B03。64 MiB 单指标文件、200 万行上限是当前安全边界，未来大文件应改为流式解析。真实用户训练结果覆盖为零；四格式夹具均为原创合成数据。schema v0 迁移只覆盖本项目声明的三个旧字段，不推断未知旧格式。未在桌面 UI 中呈现结果。
