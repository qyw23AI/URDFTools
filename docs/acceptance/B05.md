# B05 外部训练结果公平对照与统计验收

2026-10-23。`compare_conditions` 核对机器人类别、算法/任务协议及版本、奖励哈希、训练预算和地形/推扰条件。固定配方要求相同配方哈希；有界调参要求相同搜索预算，两轨不混排。不同奖励、地形版本或成功定义不可比。相同数字的训练 seed 不自动视为配对，只有两侧显式声明 `paired_seed_design=true` 且集合相同才配对 bootstrap。

`compare_success` 先在每个独立训练 seed 内统计测试 episode 成功率，再跨 seed 求均值。训练失败计 0 并单列；缺失 run 单列且不输出差值/排名；单 seed 只描述，不给跨训练 seed CI。至少 3 seed 时用固定 RNG 的 2000 次 seed 层 bootstrap 求 95% 区间，不把 episode 或视频帧当独立训练样本。

正式 `.venv/bin/python scripts/accept_phase.py B05` **1/1 gate、3 项测试、0 skip**。已知三 seed 夹具参考 `[0.5,0.25,0.75]`、候选 `[0.75,0.5,1.0]`，差 0.25；显式配对时 CI `[0.25,0.25]`，无配对声明则用独立 seed bootstrap。训练失败、缺失、单 seed、不同奖励、有界调参预算不等和重复训练 seed 均有实际负例。证据 `artifacts/acceptance/B05.json`、`artifacts/B05/runs/`。

限制：全为原创合成统计夹具，真实标准训练结果覆盖为零。未实现 IQM/rliable、视频证据或受控消融因果推断；未知控制/执行器/观测定义还需 B08 或人工审核，当前字段不能证明完整公平。
