# B04 地形与推扰外部结果协议验收

2026-10-23。`validate_protocol` 保存地形类别（平地、坡面、台阶、障碍、粗糙）、生成器版本、物理/腿长归一化轨道、大小与明确单位、推扰力 N/持续时间 s、训练/测试 seed 和成功定义。坡面用度，平地大小为零，其他地形分别用米或腿长比；归一化协议必须提供测量的腿长。训练/测试 seed 相交立即拒绝。`compare_protocols` 对版本、尺度模式、单位和成功定义差异报告不可比，对地形大小、推扰条件和测试 seed 差异报告有条件可比，逐字段列出理由。`summarize_episodes` 只统计 held-out test seed 的布尔成功，按地形类别/版本输出计数和通过率，重复 episode 或训练 seed 被拒绝。

正式 `.venv/bin/python scripts/accept_phase.py B04` **1/1 gate、3 项测试、0 skip**。已知四个测试 episode 中三次成功，得到 0.75；训练 seed 混入测试、重复 episode 均拒绝。地形生成器 v2→v3 与物理/归一化轨道混用不可比；推扰 10→15 N 为有条件可比；seed 泄漏明确进入不可比报告。坡面、台阶、障碍、粗糙和平地的单位/大小契约均有实际单元输入。日志 `artifacts/B04/runs/`，机器摘要 `artifacts/acceptance/B04.json`。

限制：这里验证的是导入的外部条件与结果标签，不生成地形、不运行训练器。合成测试 episode 不是真实机器人通过率；没有独立训练 seed 的统计区间，后续 B05 才做分层统计与公平对照。不同物理尺度的地形不能因数字相近而自动视为同条件。
