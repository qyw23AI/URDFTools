## 来源与限制

实现为本项目 Python 标准库代码，没有下载/复制第三方源码或新增包，没有变更 GPU 驱动或全局 Python。现有 Codex CLI 版本、路径与二进制 SHA256 见 provenance；升级 CLI 后必须重跑真实协议及小任务验收。接口依据本机 CLI 帮助/生成 schema 和 [OpenAI app-server 文档](https://learn.chatgpt.com/docs/app-server)、[配置文档](https://learn.chatgpt.com/docs/config-file/config-reference)、[非交互输出文档](https://learn.chatgpt.com/docs/noninteractive)。这些来源不证明当前账号具有模型权限；只有实际成功推理才可证明该次访问。

仍需在有现有 ChatGPT 路由/网络和用户 systemd 权限的同一主机环境：重跑真实 CLI 烟测；安装 service/timer 并重载；验证短 timer 实际触发；重跑本地测试和 S00 附加 gate。当前沙箱禁止权限提升，未尝试绕过总线或写入限制。真实烟测记录对应当时源码哈希，后续本地修正后的代码尚未再次通过真实烟测，门禁会检查新哈希。

工作树应由调度器独占；已有修改、已检测冲突都受保护，但同一 UID 的并发编辑无法从文件内容可靠区分“agent 写入”和“外部写入”。checkpoint 保存/恢复途中硬崩溃可能要求根据保留的 checkpoint.json 手工核对并恢复；不会丢弃保存副本或自动覆盖冲突。SIGKILL 无法由被杀进程捕获，service 的 control-group 是外层保护；重启恢复能清理身份仍匹配的 leader 进程组，leader 已消失或 PID 身份不匹配时不冒险杀不相关进程。日志和证据需要后续轮次的保留/磁盘容量管理。仅自定义 gate 计数不能证明测试语义；任务实现与验收代码仍需审阅。
