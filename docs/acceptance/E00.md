# E00 评估方法审查与金标准故障集验收

2026-10-23。将 `docs/EVALUATION.md` 与 `docs/RESULTS_DATABASE.md` 转成可执行判定合同 `docs/EVALUATION_PROTOCOL.md`：E0 描述、E1 物理、E2 无训练探测、E3 外部训练结果、E4 外部复验分层；明确确定错误、依赖设计 sidecar 的不一致及待复验假设。一次训练失败不能归因机械；固定 frame 与空腔质心不得误报。

原创 CC0 的九份 `tests/fixtures/E00/` URDF 覆盖四足/人形正常模型、视觉尺度 1000 倍、零轴、与设计 sidecar 冲突的非零轴、正定但违反主惯量三角约束、负惯量、无惯量固定 IMU frame、质心位于空腔但有解析惯量的合法框架。manifest 明确 `synthetic_fixture`，不含任何真实训练基准数据。独立测试解析树、质量、轴、尺寸比、惯量、固定 frame 和空腔数值，检查预期故障位置及合法反例。

正式 `.venv/bin/python scripts/accept_phase.py E00`：**2/2 门禁通过，0 失败，0 跳过**；4/4 数值测试通过。真实 MuJoCo 成功编译四足 8 DOF、人形 4 DOF、固定 IMU 4 DOF、中空框架 0 DOF，也**成功编译**视觉误单位及非零错轴夹具；零轴、三角约束违反及负惯量被拒绝。后两种可编译故障证明 E1 不能仅依赖编译。机器证据 `artifacts/acceptance/E00.json` 与 `artifacts/E00/runs/`。方法学依据 [Drake 惯量文档](https://drake.mit.edu/doxygen_cxx/classdrake_1_1multibody_1_1_rotational_inertia.html)、[MuJoCo 文档](https://mujoco.readthedocs.io/en/stable/XMLreference.html)、[ROS urdfdom 惯量讨论](https://github.com/ros/urdfdom/issues/138)。

限制：九份均为合成教学夹具，未给 A1/Go2/G1/H1 性能结论；E01 才实现检测器，E02–E04 才进行动力学与无训练探测。设计 sidecar 的可靠性需单独审查，不能把预期轴和尺寸当作由 URDF 自证的事实。
