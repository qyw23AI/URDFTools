## 实现
新增 `python/urdftools/evaluation/skills.py` 数据型技能加载/执行接口，`skills/builtin/` 四项原生技能（惯量、旋转坐标、库仑接触力、样本统计），`skills/local/` 用于用户自行放置 manifest。manifest 包含 schema_version、唯一 ID、semver、source、description、规则工具白名单、版本和 SHA256 来源指纹；没有脚本执行/任意文件读取或修改 URDF 的权限。技能调用显式输入，返回规则 ID、数值和判定，不擅自生成动力学/训练因果结论。

## 真实执行
```bash
.venv/bin/python scripts/accept_phase.py K00
```
- `safe-skill-registry-and-numerics`：8 项 unittest 全通过。独立临时目录中新建本地 `custom_frame` manifest，扫描发现、执行旋转矩阵数值检查；未授权工具、未知字段、目录符号链接、NaN 和 bool 伪数值被拒。正交旋转/反射、惯量三角不等式、摩擦锥内外、统计样本不足均有数值断言。
- `installed-skill-numerical-smoke`：读取项目实际四个 JSON manifest，分别计算惯量主矩 [2,3,4] kg·m²、90° 旋转正交性和行列式 1、摩擦裕量 2 N、4 样本均值 3.5/标准差 1.290994，均通过。
- 首次 gate 因 `.venv` 非 editable 安装无法找到新 evaluation 模块而 **0/2 失败**；按已有 E01 路径方案为测试/CLI 加入源码路径后正式复验通过。失败日志保存在 `artifacts/K00/runs/`；正式机器证据 `artifacts/acceptance/K00.json`，含命令、日志和 SHA256。

## 来源与限制
四个 manifest、数值测试均为本项目原创 synthetic_fixture，不是厂商/真实机器人数据。惯量仅检查张量基本物理约束；接触仅验证给定力在摩擦锥内，不推断步态稳定性；样本区间是描述性正态近似，不构成显著性或训练性能结论。技能目前通过 Python API 执行，尚未接入 Electron 技能管理页、A02 MCP tools/list 或特定 A1/Go2/G1/H1 机器人角色映射；留给 K01/K02 及后续集成。未执行 RL 训练，未触碰调度器 state、未 push。
