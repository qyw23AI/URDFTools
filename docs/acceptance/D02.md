# D02 机械组报告与 CAD 零件映射验收（2026-10-23）

结果：正式 3/3 gate 通过，6 个负向/正向校验测试、实际 FreeCAD STEP 变体解析、中文 HTML 和可复制中文的 PDF 导出。首次 PDF 测试错误地要求正文包含标题（标题实际在 PDF metadata 中），修正测试后复跑通过，原始失败记录保留在 artifacts/D02/runs/。

真实 FreeCAD 桥将 base/resized/topology FCStd 导出 STEP，OCP 比较得到 ArmLink 的几何差异和 BaseBracket 未匹配对象；使用**显式 synthetic_fixture 映射**把 ArmLink 标记为候选 URDF leg/hip，并保留拓扑改变需人工确认，原始 CAD/URDF 未被覆盖。并不声称此映射来自真正用户的 SolidWorks 装配特征树。

接入 D00 诊断图、D01 提议及 B07 真实存在的视频面板截图，本地 href 已核验文件路径和 SHA256。原 D01 示例的 evidence:d00 不存在于 D00 证据索引，准确保留 unresolved_evidence_ids；相互来源不一致的 E04 控制器证据为 cross_source_unverified，不做机械因果声明。报告显示预测腿长 100→120 mm、预估质量变化、竞争性候选原因和复验步骤，始终 requires_human_confirmation、automatically_applied=false。

主要证据：artifacts/acceptance/D02.json、artifacts/D02/mechanical-report.json、artifacts/D02/mechanical-report.html、artifacts/D02/mechanical-report.pdf 和按阶段留存的日志。PDF 通过本机 LibreOffice 7.3 无头转换，pdftotext 核验中文和 CAD 零件文字；此前独立 Electron printToPDF 试验遭到 Chromium 崩溃，因此改用本机转换工具，未掩盖失败。

局限：仍没有用户 CAD 真实零件映射、已审核外部训练结果或独立机械实验，不能将合成夹具差异归结于真实机器人设计。旧任务关于训练器的描述由 docs/RESULTS_DATABASE.md 更新为外部结果数据分析范围。不改 scheduler/state.json、不 push。
