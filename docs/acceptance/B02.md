# B02 四足结果语义与精确模型关联验收

2026-10-23。新增 `evaluate_quadruped`，要求用户明确给出前左/前右/后左/后右足端到外部时序字段的四个一一映射；算法不按名字猜方向。时间单位秒，速度 m/s，接触为布尔；对区间左端接触状态积分得到各足占空比和接触期滑移距离，从相邻触地事件估计步频，计算命令/实际速度 RMSE 与跌倒进入事件数。缺接触、足速度、跟踪或跌倒字段则输出 `null` 与 unknown 清单；扭矩饱和没有外部测量时始终为 `null`，不从视频臆测。

`ResultCatalog.link_model` 对已导入的外部 run 强制核对原始机器人 URDF 的 SHA-256 与类别，记录型号/版本/来源；A1/Go2 的厂商 URDF 与原创用户四足 URDF 都用本地实际文件在临时注册表中做了关联。所有相关实验指标均为自制合成夹具，接口返回 `reference_performance=false`，绝不把厂商模型关联误读为厂商训练成绩。

正式 `.venv/bin/python scripts/accept_phase.py B02`：**1/1 gate、4 项测试、0 skipped**。9 帧 8 秒合成时序期望：占空比 0.5、步频 0.25 Hz、滑移 0.4 m、RMSE 0.2 m/s、跌倒 1 次；交换前后左右源字段后仍按显式映射计算。缺字段时未知，重复源映射/非有限速度/非递增时间拒绝。实际 A1、Go2、用户 URDF 三份结果关联成功，A1 run 强连 Go2 模型失败。证据在 `artifacts/acceptance/B02.json` 与 `artifacts/B02/runs/`。

限制：步频只有两个以上同足触地事件才有值；滑移来自外部记录的足端速度，不对普通视频估算。接触时序是演示性夹具，未导入真实用户训练结果或厂商步态性能。不同接触采样率、传感器误差和地形对照属于后续数据协议/统计阶段；训练性能与机械因果关系不在此阶段判断。
