# A00 受约束 Agent 工具层验收

2026-10-23。完成仅允许 `preview_recipe` 的模型工具目录、完整配方 JSON 白名单、真实 CAD 几何预览、显式人工确认应用和版本冲突校验。模型没有应用工具；建议构建在项目 `proposals/`，确认前 `current.json` 字节不变。拒绝附带 shell、网络地址、脚本字段，拒绝篡改预览、旧版本及无确认应用。

适配器包括已登录 ChatGPT 的 Codex CLI 与用户自行启动的回环本地模型。CLI 调用使用临时工作目录、只读沙箱、临时会话、忽略用户自定义配置，并剔除继承的 API 密钥；预检要求 `Logged in using ChatGPT`，没有付费 API 回退。发送给 CLI 的内容仅为当前配方、版本号和建模指令；不发送 STEP/FCStd、项目文件或密钥。本地 HTTP 仅允许回环地址及指定端点，禁用代理和重定向。两种适配器均只返回严格校验的建议，不直接写入项目。

正式 `.venv/bin/python scripts/accept_phase.py A00`：**2/2 门禁通过，0 失败，0 跳过**。真实 Codex CLI 将自制 Body 宽度 20 mm 改为 30 mm，其余值不变；真实 CAD 预览质量由 0.0027 kg 增为 0.00405 kg，确认后版本由 1 增为 2。负向测试验证非法字段、失败 CLI、伪造响应、凭据剔除、远程模型端点拒绝；本地 HTTP 使用测试回环服务验证传输。机器记录见 `artifacts/acceptance/A00.json` 和 `artifacts/A00/runs/`。

限制：真实 CLI 仅用原创合成配方验证，未对用户私有 CAD 测试；本地模型适配器只经本地测试服务验证，未宣称特定模型质量。Agent 尚未集成 Electron 交互界面（A01）或 MCP（A02）。只读 CLI 沙箱和独立工作目录约束执行行为，但用户应继续审查模型返回的 CAD 修改；几何数值变化不能证明机械设计或强化学习性能改进。
