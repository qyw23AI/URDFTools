## 必须实际验证

2026-10-23 用户修订：D03 由网页 ChatGPT 经已授权 web-codex-tunnel 插件提交实际带 evidence id 的建议，替代额度耗尽的 Codex CLI；真实完成诊断和 CAD 预览、来源约束、Electron 交接验证，原模型仅经人工确认才能应用。网页会话必须由用户显式发起：插件并非桌面软件可直接调用的自动模型 API。缺失或矛盾数据被保留，引用无法解析则报告失败。

2026-10-23 追加修订：在既有网页 WebCodex 交接外，恢复可选的 Codex CLI 直接模型模式。两种模式均由用户在桌面端明确选择；CLI 仅在点击运行后调用已登录的 ChatGPT Codex，网页模式不冒充自动推理 API。两条路径必须使用同一证据校验、来源版本检查、预览及人工应用边界。

运行阶段声明的测试，保留输入 fixture、命令、输出摘要和失败记录。实现应有真实流程/数值断言，不能只做 mock、占位、文件存在性断言或全 skip。写 `docs/acceptance/D03.md`：完成内容、实际测试和结果、来源、限制、剩余风险；更新 PROGRESS.md。调度器负责决定是否完成并提交，模型不得自行写 `.scheduler/state.json` 或 Git commit。

本阶段不要把未来阶段的工作简化为虚假 completed。如硬件/输入阻塞，给明确状态和可继续的独立工作。严格遵循 AGENTS.md、docs/SCHEDULER_DESIGN.md 的授权与额度边界。
