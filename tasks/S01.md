# S01 项目与可复现工具链

级别：ordinary。依赖：S00。对应需求详见 docs/REQUIREMENTS.md；通用架构见 docs/ARCHITECTURE.md。

## 交付范围

建立独立 Python3.12/Node 环境、锁文件、核心包/桌面 app 骨架、真实多阶段验收启动器、第三方版本和许可账本。

## 必须实际验证

全新目录能安装、启动 CLI/服务/前端空壳；验收器发现测试数量并拒绝全 skip，离线失败说清依赖。

运行阶段声明的测试，保留输入 fixture、命令、输出摘要和失败记录。实现应有真实流程/数值断言，不能只做 mock、占位、文件存在性断言或全 skip。写 `docs/acceptance/S01.md`：完成内容、实际测试和结果、来源、限制、剩余风险；更新 PROGRESS.md。调度器负责决定是否完成并提交，模型不得自行写 `.scheduler/state.json` 或 Git commit。

本阶段不要把未来阶段的工作简化为虚假 completed。如硬件/输入阻塞，给明确状态和可继续的独立工作。严格遵循 AGENTS.md、docs/SCHEDULER_DESIGN.md 的授权与额度边界。
