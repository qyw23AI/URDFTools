# D02 机械组报告与 CAD 映射

级别：ordinary。依赖：D01, M02, B07。对应需求详见 docs/REQUIREMENTS.md；通用架构见 docs/ARCHITECTURE.md。

## 交付范围

按 part/joint/单位、证据、预测、局限和复验动作生成中文报告及 HTML/PDF 可读导出。

## 必须实际验证

夹具中故障能定位 CAD 零件；未匹配拓扑明确提示，所有曲线/视频链接真实可打开。

运行阶段声明的测试，保留输入 fixture、命令、输出摘要和失败记录。实现应有真实流程/数值断言，不能只做 mock、占位、文件存在性断言或全 skip。写 `docs/acceptance/D02.md`：完成内容、实际测试和结果、来源、限制、剩余风险；更新 PROGRESS.md。调度器负责决定是否完成并提交，模型不得自行写 `.scheduler/state.json` 或 Git commit。

本阶段不要把未来阶段的工作简化为虚假 completed。如硬件/输入阻塞，给明确状态和可继续的独立工作。严格遵循 AGENTS.md、docs/SCHEDULER_DESIGN.md 的授权与额度边界。
