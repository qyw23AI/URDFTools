# S00 加固自动开发调度器

级别：complex。依赖：无。对应需求详见 docs/REQUIREMENTS.md；通用架构见 docs/ARCHITECTURE.md。

## 交付范围

实现模型可用性与 ChatGPT 身份/额度预检、结构化结果、依赖图、分阶段 gate、限时/信号处理、失败恢复、证据日志与 Git 事务；保留用户最新要求的 4 小时 timer。

## 必须实际验证

真实 CLI 小任务与故障注入测试：零测试、partial 退出0、429、额度未知、进程中断、重复运行、Git 恢复。不可缩减后续计划。

运行阶段声明的测试，保留输入 fixture、命令、输出摘要和失败记录。实现应有真实流程/数值断言，不能只做 mock、占位、文件存在性断言或全 skip。写 `docs/acceptance/S00.md`：完成内容、实际测试和结果、来源、限制、剩余风险；更新 PROGRESS.md。调度器负责决定是否完成并提交，模型不得自行写 `.scheduler/state.json` 或 Git commit。

本阶段不要把未来阶段的工作简化为虚假 completed。如硬件/输入阻塞，给明确状态和可继续的独立工作。严格遵循 AGENTS.md、docs/SCHEDULER_DESIGN.md 的授权与额度边界。
