# C02 关节分组与转换向导

级别：complex。依赖：C01, S04。对应需求详见 docs/REQUIREMENTS.md；通用架构见 docs/ARCHITECTURE.md。

## 交付范围

零件成 link 分组、父子树、类型/轴/原点候选、用户确认及配置重用，实时三维预览。

## 必须实际验证

重做同一配置得到等价 URDF；改错关节轴后动画符合预期，候选不能自动冒充已确认。

运行阶段声明的测试，保留输入 fixture、命令、输出摘要和失败记录。实现应有真实流程/数值断言，不能只做 mock、占位、文件存在性断言或全 skip。写 `docs/acceptance/C02.md`：完成内容、实际测试和结果、来源、限制、剩余风险；更新 PROGRESS.md。调度器负责决定是否完成并提交，模型不得自行写 `.scheduler/state.json` 或 Git commit。

本阶段不要把未来阶段的工作简化为虚假 completed。如硬件/输入阻塞，给明确状态和可继续的独立工作。严格遵循 AGENTS.md、docs/SCHEDULER_DESIGN.md 的授权与额度边界。
