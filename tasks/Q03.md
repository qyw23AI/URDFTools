# Q03 软件发行验收审查

级别：ordinary。依赖：Q02, B08, B06。对应需求详见 docs/REQUIREMENTS.md；通用架构见 docs/ARCHITECTURE.md。

## 交付范围

复核功能需求 R01-R13、许可证、测试与真机运行材料，软件就绪标志仅按已验收项写入。

## 必须实际验证

所有必需 UI/CLI/CAD/agent/CPU 训练通路实际过关；缺 GPU 项被标可选而非伪通过。

运行阶段声明的测试，保留输入 fixture、命令、输出摘要和失败记录。实现应有真实流程/数值断言，不能只做 mock、占位、文件存在性断言或全 skip。写 `docs/acceptance/Q03.md`：完成内容、实际测试和结果、来源、限制、剩余风险；更新 PROGRESS.md。调度器负责决定是否完成并提交，模型不得自行写 `.scheduler/state.json` 或 Git commit。

本阶段不要把未来阶段的工作简化为虚假 completed。如硬件/输入阻塞，给明确状态和可继续的独立工作。严格遵循 AGENTS.md、docs/SCHEDULER_DESIGN.md 的授权与额度边界。
