# C03 URDF/ROS 包导出与交叉校验

级别：complex。依赖：C02。对应需求详见 docs/REQUIREMENTS.md；通用架构见 docs/ARCHITECTURE.md。

## 交付范围

导出自包含 URDF+mesh+元数据 ZIP/目录；独立解析器和 MuJoCo 编译反馈损失。

## 必须实际验证

真实 STEP→包→重新导入→FK/质量一致；错误材料/缺文件阻止宣称仿真就绪。

运行阶段声明的测试，保留输入 fixture、命令、输出摘要和失败记录。实现应有真实流程/数值断言，不能只做 mock、占位、文件存在性断言或全 skip。写 `docs/acceptance/C03.md`：完成内容、实际测试和结果、来源、限制、剩余风险；更新 PROGRESS.md。调度器负责决定是否完成并提交，模型不得自行写 `.scheduler/state.json` 或 Git commit。

本阶段不要把未来阶段的工作简化为虚假 completed。如硬件/输入阻塞，给明确状态和可继续的独立工作。严格遵循 AGENTS.md、docs/SCHEDULER_DESIGN.md 的授权与额度边界。
