# 验收产物的保存规则

`artifacts/acceptance/<阶段>.json` 是简短的机器验收摘要，随源码提交；`docs/acceptance/<阶段>.md` 记录人类可读结论。

`artifacts/<阶段>/` 保存测试日志、失败现场、工作流快照、截图及可能的大媒体文件，默认仅留在本机，不继续进入源码 Git。调度器的完整运行记录与断点保存在 `.scheduler/runs/` 和 `.scheduler/checkpoints/`。不要把用户 URDF/CAD、视频、模型权重或认证材料加入源码仓库。

历史 S00 验收证据已经提交，保留在 Git。历史 S02 临时日志在其完成提交 `c670677` 中可追溯；本次从当前版本的跟踪清单移出，但本地文件原样保留。全新检出可运行阶段验收重新生成本地日志。机器摘要不代表所有原始结果都被版本控制。
